## Risks and open concerns
- OTA TLS capped at 1.2 (like CelesTrak): if GitHub or CelesTrak drop 1.2, devices fail closed until an update. A host CA change while a device is offline longer than a release cycle strands it until USB.
- `failed_build` remembers only the last failure. A power cut between saving `pending_build` and writing `otadata` would mark that build failed (harmless: the next build installs).
- The 2026-11-06 device-app `NO FRAME` (cause unknown; KoD/NIST candidates fixed by 0080–0082) has not recurred; a recurrence blocks gift readiness. The app now resets on panic.
- BOOT: ~34–41 ms sampling gap during Wi-Fi association; GPIO0 polarity/20 ms debounce provisional ([0068](decisions/0068-boot-selection-gesture.md), [0070](decisions/0070-boot-input-capture-independent-of-render.md)). Fetch TLS stalls the display ~450–485 ms (VCOM 500 ms); CPU0 stack ~21 KiB; selection ~165 ms and knob ~86 ms frame hitches accepted ([0060 note](decisions/0060-defer-timing-to-physical-prototype.md#note--2026-11-05-24-hour-soak-limits-accepted)).
- Host-tested only: post-GET fetch failures, a >100 ms SNTP jump, near-budget NIST replies, settings/otadata cut-write points.
