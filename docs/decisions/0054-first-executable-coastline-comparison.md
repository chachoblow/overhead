# 0054 — First executable coastline comparison, not shipping acceptance

Date: 2026-10-20
Status: approach and implementation authorized; host comparison implemented and user visually accepted; no-omission proof, target performance and physical-display acceptance open

## Decision

Treat coastlines as orientation graphics on a small 1-bit display, **not** pixel-perfect reference geography. The user validated the **40 km simplified appearance** for this comparison and authorized proceeding with one bounded executable slice. This does not reopen [0053](0053-no-resolvable-coastline-omissions.md): a resolvable, screen-relevant coastline may not routinely gain gaps or disappear due to a numeric/work threshold. At 0.1°–<5°, [0051](0051-angular-coastline-appearance-direction.md) remains an evidence-gated investigation, not a new accuracy promise.

For genuinely invalid coastline data or an irrecoverable coastline-only calculation failure, **clear any coast ink and show a separate `COAST ERROR` notice**, preserving Earth, satellites, selection, glyphs and existing notices. A draw-target/physical write error fails the whole frame, not just the coast. The user separately approved this exceptional treatment. A difficult but resolvable view is not an exceptional failure policy.

## Bounded first host comparison

The pinned [Natural Earth candidate](0052-natural-earth-coastline-candidate.md) is exported by the checked [generator and provenance](../../render/assets/README.md) using 40 km ECEF reduction and a trial 1e-4° integer encoding. The renderer reads the static 15,484-byte part/vertex asset without heap allocation, scans all 1,734 retained segments with finite ≤0.2° interpolation and 24-step tangent bisection, clips camera-facing surface strokes to the wide rectangle, then draws coast before limb, aim point, arrows, markers, strip and white-backed notices. It checks asset boundaries and coordinates before drawing. A coastline-only failure clears the frame and repaints without coast, with `COAST ERROR`; display errors propagate as frame errors. Square/circular radar output does not use the asset. No runtime fetching, new dependency or firmware work.

The checked decoded export has **23,377 interpolated intervals** (maximum 108 steps per stored segment); the runtime checks these limits before writing pixels. The user reviewed [seven retained executable scenes](../mockups/0061-first-executable-coastline-review.md) and tried the simulator, confirming that the 40 km coastline appearance looks good in both. This accepts the visual comparison, not the renderer's numerical completeness or device performance. The per-segment bounds and finite dataset ensure the comparison terminates; they are **not** a certified visibility/error bound or an S3 time limit. In particular endpoint/midpoint visibility plus fixed sampling can miss a narrower visible excursion; integer-line raster differs from the offline continuous-stroke diagnostic. Neither small quantization nor 40 km reduction proves all tight-zoom coast pixels. This is a concrete comparison to review and improve, **not proof that 0053's no-omission condition has been met on every supported scene**. Do not treat a sample that hides visible geography as approved normal behavior.

## Remaining gates

The retained executable scenes and interactive simulator appearance have been visually accepted. Additional no-coast controls and difficult edge/tangent, selected/empty/notice cases remain needed to test the no-omission and compositing constraints; visual acceptance alone cannot prove them. Host tests isolate invalid asset and square/circular behavior; further controlled crossing, late-failure and sampling tests are needed before declaring no ordinary omission. Compare observed compiled addition, S3 full coast rebuild and scratch against [provisional gates](../evaluations/m4-coastline-budget-preflight.md) only after **separate firmware/hardware authorization**. Sharp/display throughput, whole-device frame time/stack and physical-display acceptance remain open; frozen M2 evidence is unchanged. If this simple candidate cannot pass those gates, revise or reject it—not downgrade 0053 silently.
